# Theme reference

A theme is a folder: `~/.config/harv/themes/<id>/theme.toml` (+ optional `style.css`, `fonts/`). Install one with
Preferences → Theme → *Install from folder / .zip*, or `harv --install-theme <folder|.zip>`. Check one with
`harv --validate-theme <id|folder>` (parses, resolves `extends`, loads every variant in both schemes, warns about low contrast).
Editors: `#:schema ../../docs/theme.schema.json` on the first line of `theme.toml` gives completion (Taplo / Even Better TOML).
A working example is in `docs/examples/catppuccin/`. Layout (`[shell]`, `[page.*]`) and `[lyrics]` are described in `THEMING_DESIGN.md`.

## Smallest theme

```toml
[meta]
name = "Mine"
extends = "blur"     # inherit every key you don't set
scheme = "dark"
[colors]
derive = true
bg = "#101418"
fg = "#e6edf3"
accent = "#58a6ff"   # or "cover" to follow the artwork
```

## `[colors]`

Formats: `#rgb`, `#rrggbb`, `#rrggbbaa`, `rgb()`, `oklch(L C h)`.

| Key | Used for |
|---|---|
| `bg`, `sidebar`, `raise`, `hover` | page, sidebar, popups/cards, hover rows |
| `fg`, `dim` | text, secondary text |
| `accent`, `accent_on` | accent (or `"cover"`), text on it |
| `play_bg`, `play_fg` | play buttons |
| `bar_bg`, `bar_fg` | bottom player bar |
| `toast_bg`, `toast_fg` | toasts |
| `np_fg`, `np_on` | full-screen lyrics page text / play-button icon (sits on the cover backdrop) |
| `line`, `selected`, `focus`, `scrim`, `danger`, `success`, `warn` | extras for your `style.css` as `@line` …; always defined, derived when omitted |

**`derive = true`** (in `[colors]`): with `bg` and `fg` set, every key you leave out is computed (OKLab mixes of bg/fg, readable text on the accent) instead of inherited from `extends`. If there is no `[colors_alt]`, the opposite-scheme palette is generated by flipping bg/fg lightness (hue and accent kept). Give a `[colors_alt]` with its own `bg`+`fg` to take control of it.

## Variants

```toml
[variants.latte]
name = "Latte"
scheme = "light"          # optional; otherwise decided by the background's lightness
[variants.latte.colors]   # same keys as [colors]; missing ones derive from its bg/fg
bg = "#eff1f5"
fg = "#4c4f69"
[variants.latte.colors_alt]   # optional; generated when absent
```

Pick one from the palette menu on the theme's card. The choice is remembered per theme.

## Numeric tokens

| Table | Keys |
|---|---|
| `[shape]` | `xs sm md lg input xl control cover hero` (px radii, `control` 9999 = pill) |
| `[metrics]` | `sidebar_w track_row_h label_tracking border_w` (hairline width, 0 = none) |
| `[effects]` | `ambient bar_tint` (cover wash 0..1), `shadow` (drop-shadow multiplier, 0 = flat), `motion` (duration multiplier, 0 = instant) |
| `[vars]` | your own: `glow = 0.35` → `{{glow}}` |

## `style.css`

Appended after the app stylesheet. It is templated like the app's own CSS:

- `{{r_md}}` `{{r_lg}}` … radii, `{{border_w}}`, `{{sidebar_w}}`, `{{track_row_h}}`, `{{font_ui}}`, `{{font_mono}}`, plus your `[vars]`.
- `{{c_bg}}` `{{c_fg}}` `{{c_accent}}` (fixed accents only) … every colour as a literal, for places `@name` cannot go.
- `{{shadow:0.4}}` → that alpha × `effects.shadow`; `{{ms:150}}` → `150ms` × `effects.motion`.
- GTK named colours: `@bg @bg_side @bg_raise @bg_hover @fg @fg_dim @accent_on @play_bg @play_fg @bar_bg @bar_fg @toast_bg @toast_fg @np_fg @np_on @lib_accent` and the extras above.
- `/* comments */` are removed before substitution, so a `{{` inside one is harmless.
